Background & Context

Forbidden endpoints model auxiliary resources needed to initiate or complete jobs; processing can continue across forbidden instants. Earlier XP bounds motivated parameterized questions. The prior record understated the high-multiplicity Fse result and did not distinguish its integer-time assumptions from unspecified real-time schedules. Forbidden-start-only (Fs) and forbidden-start-and-end (Fse) results also require separate treatment.

Statement & Model

Consider a single machine and a set of nonpreemptive jobs with processing times. There is also a set FFF of τ\tauτ forbidden time points. A feasible schedule processes one job at a time and must avoid starting or completing any job at a forbidden time point; equivalently, every job start time and completion time must lie outside FFF. The objective is to minimize the makespan. The original target is an algorithm with running time f(τ)LO(1)f(\tau)L^{O(1)}f(τ)LO(1), where LLL is the encoded input length, or a parameterized hardness classification. The record did not specify the time domain. Gabay, Rapine, and Brauner's Theorem 3 proves FPT for integer data and integer start/completion times, including high-multiplicity encoding. This settles that discrete-time interpretation, not unrestricted real-time schedules without a reduction or discretization argument. The original target is retained with this scope caveat.

What Is Known

Gabay, Rapine, and Brauner, Journal of Scheduling 19(5), 609-616 (2016), Theorem 3, proves FPT in the number of forbidden start-and-end instants even with high multiplicities. The model requires integer data and integer feasible endpoints. The previous XP-only description is incorrect for that model. Billaut-Sourd concerns forbidden starts; Rapine-Brauner concerns forbidden starts and completions. No conclusion about an unspecified real-time interpretation follows without additional argument.
