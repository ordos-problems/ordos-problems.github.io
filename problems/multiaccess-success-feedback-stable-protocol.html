Short Statement

Can a deterministic update using only current attempt probability and the success bit stabilize a positive rate? Extra-randomization results do not settle this restriction.

Background & Context

Random-access channels are among the classical stochastic-network models behind communication protocols. In slotted ALOHA-type systems, many packets contend for a shared channel, and collisions force retransmission. Stability depends strongly on what feedback the protocol receives. If the controller can distinguish empty slots from nonempty slots, or collisions from noncollisions, classical results give the familiar e−1e^{-1}e−1 threshold. Foss highlights a feedback restriction: suppose the update can use only the current transmission probability and a single bit saying whether the previous slot had a success. This bit merges empty slots and collisions into the same observation, depriving the protocol of the usual congestion signal. The model is extremely clean, and the question is binary: does any protocol in this information class stabilize the backlog for any positive arrival rate? A later stability theorem uses additional common randomness, so the feedback alphabet alone does not define the admissible protocol class.

Statement & Model

Time is slotted. In each slot, a Poisson number of new packets with mean λ\lambdaλ enters a shared single channel. At the beginning of slot nnn, every packet currently in the system attempts transmission independently with probability pnp_npn​. If exactly one packet transmits, the transmission succeeds and that packet leaves; if zero packets transmit, the slot is idle; if two or more transmit, all attempted transmissions collide and remain in the system. Thus empty slots and collision slots are observationally identical. The pair (Wn,pn)(W_n,p_n)(Wn​,pn​) is then a time-homogeneous Markov chain. What Is Known

Foss-Hajek-Turlikov (2016) constructs stable doubly randomized protocols for iid finite-mean slot arrivals, including Poisson input. For each fixed interval 0<λ0<λ1<e−10<\lambda_0<\lambda_1<e^{-1}0<λ0​<λ1​<e−1, suitable parameters stabilize all rates in that interval. The feedback merges empty and collision outcomes and no test packets are used. But a shared extra coin randomizes the protocol; the theorem does not establish deterministic f(p,J), nor one parameter choice covering every unknown rate below e−1e^{-1}e−1.
