Short Statement

Close the long-standing gap between the 1.881.881.88 deterministic lower bound and the 1.92011.92011.9201 deterministic upper bound for online makespan minimization on identical machines.

Open Problem

Determine the optimal asymptotic deterministic competitive ratio for online makespan minimization on identical machines in the adversarial arrival model.

Background & Context

This is one of the canonical problems in online algorithms and one of the oldest scheduling problems in competitive analysis. The model is deliberately austere: jobs are independent, machines are identical, there are no release dates beyond online arrival, and the algorithm's only decision is which current machine receives the current job. Graham's list scheduling rule dates to the 1960s and remains the first example many researchers see of an online scheduling guarantee. The difficulty is that irrevocability creates adversarial sequences in which every load-balancing choice can be punished later. The problem is also a useful reference point for variants with random arrival order, migration, restart, preemption, semi-online information, or resource augmentation, because improvements in those variants show exactly which additional powers help and which do not address the fully adversarial list model.

The field has a stable hierarchy of results. Graham's greedy rule gives the baseline (2−1/m)(2-1/m)(2−1/m). Subsequent algorithms lowered the asymptotic upper bound below 222, with the best commonly cited deterministic value at 1.92011.92011.9201. Lower-bound constructions rule out ratios below 1.881.881.88. The modern literature has produced strong progress in nearby models: random-order arrival admits a 1.84781.84781.8478 deterministic guarantee, and bounded migration changes the achievable constants dramatically. These papers are useful because they verify that the classic adversarial no-migration gap is not a formatting artifact; it remains a real open interval. A solution likely needs either a new adversarial lower-bound family above 1.881.881.88 or a new algorithmic invariant improving on the current upper-bound machinery.
