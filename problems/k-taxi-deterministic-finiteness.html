Short Statement

A recent preprint claims a finite deterministic competitive ratio for hard k-taxi on every metric, for every k.

Claimed Resolution

Verify the reported general-k finiteness theorem; the historical existence question is no longer an unaddressed target.

Background & Context

The hard k-taxi problem charges only empty travel: each request specifies a pickup and destination, and passenger travel changes the configuration without cost. This differs from easy k-taxi, where all travel is charged. Historical small-k results did not establish a ratio depending only on k for arbitrary metrics; the new paper below reports such a bound.

Statement & Model

Let k taxis occupy a metric space. Each request is a pickup/dropoff pair (s,t)(s,t)(s,t). The chosen taxi must reach s and then carry the passenger to t; only empty travel to the pickup is charged. Compare the online total empty distance with the offline minimum from the same initial configuration. The historical question is whether a deterministic competitive ratio depending only on k exists on every metric, with any additive constant independent of the request sequence. The new theorem in the What Is Known section reports an affirmative answer for all k.

What Is Known

Coester, Huang, and Poon, 'The Online k-Taxi Problem Is Competitive on All Metrics' (arXiv:2611.06684v1, November 4, 2026), Theorem 1.1 and Corollary 1.2, give randomized 9k−19^{k-1}9k−1 competitiveness against an adaptive online adversary and deterministic 81k−181^{k-1}81k−1 competitiveness on every metric. The deterministic bound is independent of the number of points and aspect ratio. Together with the existing 2k−12^k-12k−1 lower bound this gives 2Θ(k)2^{\Theta(k)}2Θ(k) dependence; exact constants/bases remain undetermined. The adaptive-online adversary is not an almighty adversary.

Claim under review. Verify the reported general-k finiteness theorem; the historical existence question is no longer an unaddressed target.
